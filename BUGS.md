# Журнал ошибок

Каждая запись: симптом → корневая причина → исправление → как предотвращаем повторение.

## Фаза 1

### B-001 · Утечка соединений с БД между запросами
- **Симптом:** `ResourceWarning: unclosed connection` в тестах (с `filterwarnings=error` — падения
  случайных тестов).
- **Причина:** зависимость `get_session` делегировала во вложенный async-генератор
  (`async for session in session_scope(...)`). FastAPI закрывает внешний генератор, а внутренний
  закрывается только сборщиком мусора — сессия держала соединение после ответа, и `dispose()`
  не мог его вернуть.
- **Исправление:** `async with sessionmaker() as session: yield session` прямо в зависимости.
- **Защита:** тесты идут с `filterwarnings = error`, любой ResourceWarning валит прогон.

### B-002 · Шаблон маршрута в access-логе без префикса `/v1`
- **Симптом:** в логе `route=/auth/register` при запросе `/v1/auth/register`.
- **Причина:** FastAPI 0.16x подключает роутеры лениво; `scope["route"].path` содержит только
  префиксы собственного роутера, внешний `APIRouter(prefix="/v1")` теряется.
- **Исправление:** `/v1` задаётся в префиксе каждого роутера (`routers.API_V1`), без вложения.
- **Защита:** `test_access_log_records_full_route_template`.

### B-003 · `ORJSONResponse` объявлен устаревшим
- **Симптом:** `FastAPIDeprecationWarning` превращал обработку ошибки в 500.
- **Причина:** в актуальном FastAPI JSON сериализуется Pydantic напрямую; класс помечен deprecated.
- **Исправление:** стандартный `JSONResponse` в обработчиках ошибок и `/readyz`.
- **Защита:** предупреждения = ошибки в тестах.

### B-004 · Неверное ожидание коэффициента демпфирования пружины
- **Симптом:** тест генератора Kotlin ожидал `0.8333f`, генератор выдавал `0.8332f`.
- **Причина:** ошибка в тесте: 38 / (2·√520) = 0.83317… → 0.8332.
- **Исправление:** исправлено ожидание в тесте (генератор был верен).

### B-005 · Docker-сборка зависела от ghcr.io
- **Симптом:** `COPY --from=ghcr.io/astral-sh/uv` не скачивался в закрытой сети.
- **Причина:** внешний реестр как обязательная зависимость сборки.
- **Исправление:** uv ставится из PyPI (`pip install uv`), который уже нужен для зависимостей.

### B-006 · Склейка URL в генераторе `.env` при заданном домене
- **Симптом:** найдено на ревью скрипта: `SONORA_WEB_BASE_URL` получился бы `https://example.comexample.com`.
- **Причина:** `${domain:+A}${domain:-B}` — при заданном `domain` вторая подстановка возвращает сам домен, а не пустоту.
- **Исправление:** явные ветки `if` для режимов «с доменом» и «по IP».
- **Защита:** скрипт прогнан end-to-end в режиме по IP; shellcheck в проверках.

### B-007 · 503 от Caddy ~30 с после каждого рестарта
- **Симптом:** сразу после запуска стека `no upstreams available`, хотя API уже здоров.
- **Причина:** активная проверка здоровья Caddy считает upstream недоступным до первой успешной
  проверки, а интервал по умолчанию — 30 с.
- **Исправление:** `health_interval 5s`, `health_timeout 2s` — трафик идёт через ~2 с.

### B-008 · Caddy не стартовал на VPS: запасной порт 8443 тоже занят
- **Симптом:** `failed to bind host port 0.0.0.0:8443/tcp: address already in use` при первом деплое
  на сервер с VPN.
- **Причина:** при занятом 443 скрипт подставлял 8443, не проверив, свободен ли он; VPN держал оба.
- **Исправление:** `first_free_port` перебирает кандидатов (8443, 9443, 10443…) и берёт первый свободный;
  то же для HTTP.

## Фаза 2

### B-009 · Повреждённый FLAC проходил проверку
- **Симптом:** файл с 4 КБ мусора посередине декодировался ffmpeg без ошибок (`-xerror`, `-err_detect`).
- **Причина:** демуксер FLAC пересинхронизируется на следующий валидный фрейм молча.
- **Исправление:** декодированный PCM (в родной разрядности) сверяется с MD5 из STREAMINFO.
- **Защита:** фикстура `corrupt.flac`, тесты `test_probe_rejects_bad_files` и пайплайна.

### B-010 · `MissingGreenlet` после коммита в async-сессии
- **Симптом:** 500 при чтении `updated_at` у только что изменённой задачи загрузки.
- **Причина:** `onupdate=func.now()` вычисляется на сервере; после UPDATE атрибут истекал и
  дочитывался лениво — в async-сессии это запрещено.
- **Исправление:** `eager_defaults=True` на базовой модели — значения приходят через RETURNING.

### B-011 · Autoflush вставлял недозаполненный трек
- **Симптом:** `NotNullViolation track_number` на этапе catalog для файлов без номера трека.
- **Причина:** объект добавлялся в сессию до вычисления номера; запрос «следующего номера»
  вызывал autoflush с NULL.
- **Исправление:** все поля вычисляются до `session.add`.

### B-012 · Ложные дубликаты по акустическому отпечатку
- **Симптом:** при сквозном тесте разные треки отклонялись как «та же запись» (сходство 0.91).
- **Причина:** порог 0.85 был выбран без замеров; у стационарных сигналов отпечаток почти
  константный (1–2 различных значения из 302) и «похож» на любой другой такой же.
- **Исправление:** порог 0.95 по замерам (та же запись ≥0.999, разная музыка ≈0.6);
  малоинформативные отпечатки не используются для блокировки.
- **Защита:** `test_degenerate_fingerprints_are_not_informative`, проверка ≥0.99 для перекодирования.

### B-013 · Gapless: priming AAC не обрезался в HLS
- **Симптом:** HLS-вариант AAC длиннее источника на 1024 сэмпла (21 мс) — щелчок/пауза на стыке.
- **Причина:** HLS-муксер ffmpeg пишет в `init.mp4` edit list с `media_time = 0`.
- **Исправление:** `mp4.set_edit_list` переписывает `elst` (priming + длительность).
- **Защита:** тест проверяет `elst` в init-сегменте; декодированная длина совпадает с источником в начале.

### B-014 · Отсутствие ffmpeg выдавалось за «файл не аудио»
- **Симптом:** в контейнере без ffprobe задача падала с «File is not a readable audio file».
- **Причина:** любой `ToolError` на этапе probe превращался в ошибку файла.
- **Исправление:** `ToolMissingError` не маскируется; воркер проверяет ffmpeg/ffprobe при старте.

### B-015 · `create-admin` принимал адрес, с которым нельзя войти
- **Симптом:** админ `admin@e2e.test` создан, но вход отвечает 422.
- **Причина:** CLI не валидировал e-mail, а `/auth/login` отвергает зарезервированные домены.
- **Исправление:** та же валидация `EmailStr` в CLI.

### B-016 · Образы MinIO недоступны
- **Симптом:** `pull access denied for minio/minio`.
- **Причина:** MinIO прекратил публикацию community-образов.
- **Исправление:** SeaweedFS (S3 API); публичность — отдельным бакетом `sonora-public`
  (анонимное чтение по префиксу SeaweedFS не поддерживает, а на уровне бакета это переносимо на R2/B2).

## Сайт и стриминг

### B-017 · «Новые релизы» пропускали опубликованные релизы
- **Симптом:** пустая выдача при наличии готовых треков (выявлено тестом).
- **Причина:** фильтр по денормализованному `releases.track_count`, который может отставать.
- **Исправление:** `EXISTS` по готовым трекам релиза.

### B-018 · Шапка альбома почти чёрная на тёмных обложках
- **Симптом:** скриншот: градиент шапки не виден.
- **Причина:** доминантный цвет тёмной обложки близок к фону.
- **Исправление:** в оттенок подмешивается «яркий» цвет палитры (45 %).

### B-019 · 401 в консоли у каждого гостя
- **Симптом:** браузерный E2E собрал ошибки консоли на главной без входа.
- **Причина:** проверка сессии без cookie отвечала 401.
- **Исправление:** без refresh-cookie — 204; E2E требует пустой список ошибок консоли и запросов.

### B-020 · Сборка на VPS падала на `docker/dockerfile:1.7`
- **Симптом:** `failed to fetch anonymous token … auth.docker.io … TLS handshake timeout` до начала сборки.
- **Причина:** директива `# syntax=docker/dockerfile:1.7` заставляет BuildKit скачивать образ
  фронтенда с Docker Hub при каждой сборке; с сервера Docker Hub отвечает нестабильно.
- **Исправление:** директива удалена из всех Dockerfile — встроенный фронтенд поддерживает всё
  используемое (`RUN --mount=type=cache`, многостадийность). Одной внешней зависимостью меньше.

### B-021 · После обновления Caddy работал со старым конфигом
- **Симптом:** после `git pull && bootstrap.sh` контейнер Caddy остался `Running` со старыми маршрутами
  (без сайта и хранилища).
- **Причина:** Caddyfile примонтирован как файл; `git pull` заменяет его новым inode, а запущенный
  контейнер продолжает видеть старый; compose не пересоздаёт контейнер, раз его описание не менялось.
- **Исправление:** `bootstrap.sh` перезапускает Caddy после `up`.

## Управление сайтом

### B-022 · Правки после автоформатирования молча не применялись
- **Симптом:** изменение в `streaming.py` «прошло», но тест падал по-старому.
- **Причина:** скрипт заменял строку, которую ruff format уже переформатировал; `str.replace` без
  совпадения ничего не делает.
- **Исправление:** правки только с проверкой совпадения (`assert old in s`) по свежему файлу.

### B-023 · Tailwind-тема убрала `bg-white` и `text-black`
- **Симптом:** скриншот: белые кнопки стали прозрачными.
- **Причина:** тема на токенах сбрасывает палитру Tailwind целиком.
- **Исправление:** `white`/`black` возвращены в `@theme`.

### B-024 · Наклон карточек конфликтовал с анимацией появления
- **Симптом:** карточки дёргались и «забывали» наклон.
- **Причина:** Motion и ручной `style.transform` писали в одно свойство.
- **Исправление:** наклон через `useMotionValue` + `useSpring` внутри Motion.

### B-025 · Превью блока главной слало устаревшие данные (422)
- **Симптом:** E2E: 422 на `/v1/admin/home/preview` сразу после выбора картинки баннера.
- **Причина:** проверка «блок заполнен» считалась мгновенно, а тело запроса — с задержкой 400 мс;
  запрос уходил со старым телом.
- **Исправление:** тело и признак готовности дебаунсятся вместе; подсказка, чего не хватает, — на русском.

### B-026 · Ошибка гидрации React #418 на главной
- **Симптом:** E2E: `Minified React error #418` в консоли.
- **Причина:** приветствие по времени суток считалось на сервере (UTC) и в браузере по-разному.
- **Исправление:** `useSyncExternalStore`: сервер рендерит «Привет», браузер — своё время суток.

### B-027 · Новый баннер появлялся в самом низу главной
- **Симптом:** созданный баннер не виден на главной без прокрутки.
- **Причина:** новые блоки всегда добавлялись в конец.
- **Исправление:** баннеры встают первыми, остальные блоки — в конец (покрыто тестом).

### B-028 · Сайт видел только часть API-типов
- **Симптом:** `tsc`: у `HomeBlock` списки «могут отсутствовать».
- **Причина:** поля со значением по умолчанию генерируются как необязательные.
- **Исправление:** нормализация в `HomeBlockView` (пустой список по умолчанию).

## Стиль «Резонанс»

### B-029 · У артистов пропали фото на главной
- **Симптом:** скриншот: под заголовком «Артисты» только имена.
- **Причина:** обёртка аватара без ширины внутри `items-center`-колонки — `w-full` схлопывался в 0.
- **Исправление:** обёртке задана ширина (`w-full`).

### B-030 · Волновая линия рвалась посередине анимации
- **Симптом:** скриншот: линия под заголовком с разрывом.
- **Причина:** анимация через `stroke-dasharray` + `pathLength` вместе с `vector-effect: non-scaling-stroke` —
  длина штриха считается в экранных координатах, нормировка `pathLength` перестаёт совпадать.
- **Исправление:** проявление через `clip-path: inset()`.

### B-031 · Баннер-спектр выглядел пустым при двух релизах
- **Симптом:** скриншот: две узкие полосы в углу большой карточки.
- **Причина:** полос было ровно столько, сколько обложек.
- **Исправление:** между обложками — тонкие полосы эквалайзера в цветах бренда (не меньше 18 полос).

## Загрузка

### B-032 · FLAC не выбирался кнопкой «Выбрать файлы»
- **Симптом:** E2E: «Не нашлось FLAC или MP3», доходила только обложка.
- **Причина:** `accept` с MIME `audio/flac`, а FLAC часто определяется как `audio/x-flac`.
- **Исправление:** фильтр по расширениям и `audio/*`.

### B-033 · Непонятно, идёт ли загрузка
- **Симптом:** после выбора файлов ничего не происходило без нажатия «Загрузить N».
- **Исправление:** автостарт, прогресс со скоростью и ETA, этапы обработки в карточке файла.

### B-034 · Воркер на сервере не запускался («no such file or directory»)
- **Симптом:** `media-worker` в цикле перезапусков: `exec /app/.venv/bin/sonora-media-worker: no such file or directory`;
  файлы загружались, но не обрабатывались.
- **Причина:** venv собирался в `/app/media-worker/.venv`, а копировался в `/app/.venv`; в shebang
  скрипта зашит путь к интерпретатору сборки, которого в образе нет.
- **Исправление:** `UV_PROJECT_ENVIRONMENT=/app/.venv` — venv собирается там же, откуда запускается.

### B-035 · На сервере по http выбор файла ничего не делал; прослушивания не считались
- **Симптом:** после выбора трека — ни списка, ни запросов к API; в админке 0 прослушиваний.
- **Причина:** `crypto.randomUUID()` есть только в защищённом контексте (HTTPS или localhost); сайт на
  `http://IP:порт` — нет, вызов падал. E2E шёл на `127.0.0.1`, который браузер считает защищённым.
- **Исправление:** `lib/uuid` через `crypto.getRandomValues` (работает везде); E2E теперь гоняется и
  по внешнему IP (`isSecureContext === false`).

## Звук (аудит A1–A8, подробно в AUDIT.md)

### B-036 · Перемотка назад заново скачивала аудио
- **Причина:** короткий back buffer, лимит MSE в Chrome, новая подпись ссылки на каждый запрос + `no-store`.
- **Исправление:** сессионный LRU-кэш сегментов в загрузчике hls.js (`player/segmentCache.ts`).

### B-037 · hls.js выкачивал весь трек при старте
- **Причина:** `maxBufferSize` (60 МБ) пересчитывается в секунды по битрейту — для аудио это десятки минут.
- **Исправление:** `maxBufferSize: 0`, `maxBufferLength: 40`.

### B-038 · Качество: несуществующие варианты и остановка при ошибке декодера
- **Исправление:** `renditions` в `/stream`, фильтр по `MediaSource.isTypeSupported`, автопереход на AAC 256.

## Дизайн-система

### B-039 · Часть элементов без скруглений, рядом — карточки на 28–36 px
- **Симптом:** скриншоты: строки, плитки и обложки с прямыми углами, панели — сильно скруглённые.
- **Причина:** тема на токенах сбрасывает шкалу радиусов Tailwind, а код использовал `rounded-2xl/3xl`,
  которых в теме нет, и произвольные `rounded-[28px…36px]`.
- **Исправление:** единая шкала токенов (xs 4 … 2xl 22) и миграция всех компонентов на неё.

### B-040 · Светлая тема невозможна: интерфейс рисовался белым по прозрачному
- **Причина:** ~60 классов `bg-white/…`, `border-white/…` и `rgba(255,255,255,…)` в компонентах.
- **Исправление:** цвет `fg` (текст текущей темы) для полупрозрачных поверхностей и линий.

## Медиатека, навигация, настройки

### B-041 · Настройки откатывались, если перезагрузить страницу сразу после изменения
- **Сценарий:** выбрать светлую тему → перезагрузить в течение ~0,7 с → снова тёмная.
- **Причина:** при входе клиент брал настройки с сервера, а локальное изменение ещё не успело уйти (debounce).
- **Исправление:** флаг `syncPending` в локальном хранилище — неотправленные локальные изменения побеждают и
  отправляются; отправка при `pagehide`. E2E `app-flow`: «light theme persists after reload».

### B-042 · Переименованный плейлист показывал старое название до минуты
- **Причина:** `GET /v1/playlists/{id}` отдавался с `Cache-Control: max-age=60`; браузер не ходил за свежей версией.
- **Исправление:** для пользовательских плейлистов `max-age=0` + ETag (дешёвый 304); тест на заголовок.

### B-043 · Строка трека — кнопка с кнопками внутри (WCAG)
- **Причина:** `role="button"` на строке со вложенными «сердечком» и «…»; неверное доступное имя.
- **Исправление:** строка кликабельна мышью, для клавиатуры — отдельная кнопка «Слушать: …» у номера.

### B-044 · Ошибка 404 в консоли для каждого трека без текста
- **Причина:** отсутствие текста отдавалось как 404 — браузер логирует это как ошибку загрузки ресурса.
- **Исправление:** 204 No Content для опубликованного трека без текста (404 — только для несуществующего трека).

### B-045 · `2xl:`-классы не работали, `xl:` срабатывал только с 1600 px
- **Причина:** тема на токенах сбрасывает брейкпоинты Tailwind; в токенах не было `2xl`, а `xl` = 1600.
- **Исправление:** `2xl` = 1920 в токенах; раскладка страницы артиста — по ширине контента (container query),
  потому что её меняют боковая и правая панели.

### B-046 · «Похожие артисты» показывали гостя с фита того же артиста
- **Причина:** совместные прослушивания учитывали собственные треки артиста (где гость — соисполнитель).
- **Исправление:** похожесть считается только по другим трекам; регрессионный тест.

### B-047 · «Моя волна» заканчивалась на маленьком каталоге
- **Исправление:** когда новых треков нет, исключаются только последние 10 — волна остаётся бесконечной.
