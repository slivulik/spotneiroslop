# Журнал ошибок

Каждая запись: симптом → корневая причина → исправление → как предотвращаем повторение.

## Фаза 1

### B-001 · Утечка соединений с БД между запросами
- **Симптом:** `ResourceWarning: unclosed connection` в тестах (с `filterwarnings=error` — падения
  случайных тестов).
- **Причина:** зависимость `get_session` делегировала во вложенный async-генератор
  (`async for session in session_scope(...)`). FastAPI закрывает внешний генератор, а внутренний
  закрывается только сборщиком мусора — сессия держала соединение после ответа, и `dispose()`
  не мог его вернуть.
- **Исправление:** `async with sessionmaker() as session: yield session` прямо в зависимости.
- **Защита:** тесты идут с `filterwarnings = error`, любой ResourceWarning валит прогон.

### B-002 · Шаблон маршрута в access-логе без префикса `/v1`
- **Симптом:** в логе `route=/auth/register` при запросе `/v1/auth/register`.
- **Причина:** FastAPI 0.16x подключает роутеры лениво; `scope["route"].path` содержит только
  префиксы собственного роутера, внешний `APIRouter(prefix="/v1")` теряется.
- **Исправление:** `/v1` задаётся в префиксе каждого роутера (`routers.API_V1`), без вложения.
- **Защита:** `test_access_log_records_full_route_template`.

### B-003 · `ORJSONResponse` объявлен устаревшим
- **Симптом:** `FastAPIDeprecationWarning` превращал обработку ошибки в 500.
- **Причина:** в актуальном FastAPI JSON сериализуется Pydantic напрямую; класс помечен deprecated.
- **Исправление:** стандартный `JSONResponse` в обработчиках ошибок и `/readyz`.
- **Защита:** предупреждения = ошибки в тестах.

### B-004 · Неверное ожидание коэффициента демпфирования пружины
- **Симптом:** тест генератора Kotlin ожидал `0.8333f`, генератор выдавал `0.8332f`.
- **Причина:** ошибка в тесте: 38 / (2·√520) = 0.83317… → 0.8332.
- **Исправление:** исправлено ожидание в тесте (генератор был верен).

### B-005 · Docker-сборка зависела от ghcr.io
- **Симптом:** `COPY --from=ghcr.io/astral-sh/uv` не скачивался в закрытой сети.
- **Причина:** внешний реестр как обязательная зависимость сборки.
- **Исправление:** uv ставится из PyPI (`pip install uv`), который уже нужен для зависимостей.

### B-006 · Склейка URL в генераторе `.env` при заданном домене
- **Симптом:** найдено на ревью скрипта: `SONORA_WEB_BASE_URL` получился бы `https://example.comexample.com`.
- **Причина:** `${domain:+A}${domain:-B}` — при заданном `domain` вторая подстановка возвращает сам домен, а не пустоту.
- **Исправление:** явные ветки `if` для режимов «с доменом» и «по IP».
- **Защита:** скрипт прогнан end-to-end в режиме по IP; shellcheck в проверках.

### B-007 · 503 от Caddy ~30 с после каждого рестарта
- **Симптом:** сразу после запуска стека `no upstreams available`, хотя API уже здоров.
- **Причина:** активная проверка здоровья Caddy считает upstream недоступным до первой успешной
  проверки, а интервал по умолчанию — 30 с.
- **Исправление:** `health_interval 5s`, `health_timeout 2s` — трафик идёт через ~2 с.

### B-008 · Caddy не стартовал на VPS: запасной порт 8443 тоже занят
- **Симптом:** `failed to bind host port 0.0.0.0:8443/tcp: address already in use` при первом деплое
  на сервер с VPN.
- **Причина:** при занятом 443 скрипт подставлял 8443, не проверив, свободен ли он; VPN держал оба.
- **Исправление:** `first_free_port` перебирает кандидатов (8443, 9443, 10443…) и берёт первый свободный;
  то же для HTTP.
