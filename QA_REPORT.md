## Исправлено в этом цикле
B-022…B-051 в `BUGS.md` (30 записей). В финальном QA-проходе найдено и исправлено:
- **Major**: B-050 — при долгом обрыве сети плеер мог встать на ошибку. Теперь движок ждёт сеть и продолжает с той же позиции.
- **Minor**: B-048 — горизонтальная прокрутка главной на 390 px; B-049 — бледное кольцо фокуса у поиска.
- **Trivial**: B-051 — навигации без доступных имён.

Ещё два «падения» оказались ошибками самих тестов, а не приложения. Тесты исправлены и стали строже:
- Замер памяти шёл через полные перезагрузки страницы, поэтому утечку он бы не увидел. Теперь используются SPA-переходы.
- Тест обрыва сети попадал на 55-секундный трек, который просто заканчивался. Теперь тест выбирает самый длинный трек.

## Что не проверено и почему
- **Safari, Firefox, реальные iOS/Android-браузеры** — в среде есть только Chromium.
- **Production-сервер 2.26.2.127** — доступа к нему из среды нет; проверка там — после `git pull && sudo ./infra/deploy/bootstrap.sh`.
- **LRCLIB, MusicBrainz, Wikidata вживую** — хосты закрыты сетевой политикой среды. Логика проверена на записанных ответах (MockTransport), реальные совпадения не проверялись.
- **Ветка ожидания сети в движке (B-050)** — в прогоне hls.js не дошёл до фатальной ошибки, поэтому сам код ожидания тестом не задействован. Проверено только, что воспроизведение возобновляется.
- **Android на устройстве** — эмулятора и устройства здесь нет; Android SDK недоступен (dl.google.com закрыт политикой сети). Сборка и юнит-тесты выполняются в GitHub Actions, поведение на телефоне не проверено.
- **Нагрузка с множеством одновременных пользователей** — не проводилась: нужен отдельный стенд, и на production такую нагрузку давать нельзя.

## Как повторить
```bash
/tmp/e2e-up.sh                          # или docker compose -f infra/docker-compose.prod.yml up
cd apps/web && for f in app-flow player-flow discovery-flow qa-flow themes audio-cache; do node e2e/$f.cjs; done
cd services/api && uv run pytest        # нужен Postgres
cd services/media-worker && uv run pytest
```
